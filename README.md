# 学习空间 · 培训平台 Web 原型

已整理为可直接推送 GitHub，并部署到 Vercel 或 Cloudflare Pages 的静态项目。完整操作见 [DEPLOYMENT.md](DEPLOYMENT.md)。

    npm run build

上述命令只检查静态资源完整性，不会联网、上传数据或发布站点。

无构建依赖的 HTML / CSS / JavaScript 项目，桌面设计基准 1440 × 900。

## 打开方式

直接打开 `dist/index.html`，或在项目目录运行 `python3 -m http.server 4173 --directory dist` 后访问 http://localhost:4173 。首次进入会看到角色体验入口，可选择员工端或 HR 管理端；右上角“切换体验身份”可返回入口。

## 页面

员工端：首页、我的学习、我的考试、学习记录、我的证书。可切换课程 Tab、搜索课程、打开课程详情、体验学习进度和示例考试。

HR 管理端：工作台、课程管理、培训计划、学习管理、考试测评、人员管理、培训数据、首页配置。可新增或编辑课程、培训计划、考试和人员；课程可切换草稿与发布状态，员工首页配置可修改欢迎语和 Banner 内容并在员工端预览。

### 筛选课程列表

HR 管理端的“课程管理”支持按课程名称、课程分类、面向学员范围筛选，可与“全部 / 已发布 / 草稿”状态组合使用。面向学员范围包括未指定、全体员工、指定部门和指定员工；没有配置面向学员的旧课程归为“未指定”。分类选项来自当前课程数据，新增或编辑分类后自动更新。

筛选即时生效，显示匹配数量；无匹配时可清空筛选。“重置筛选”会清空所有条件并返回全部发布状态。在同一次页面会话中切换管理页面或编辑课程会保留筛选，刷新页面后恢复默认。

### 配置课程面向学员

在“课程管理”点击“添加课程”或某门课程的“编辑”，可在“面向学员 · 需要学习的人员”中选择全体员工、指定部门或指定员工；原有未配置课程显示为“未指定”。按部门或指定员工时必须至少选择一项。保存后，课程列表会显示面向范围与当前名单中的匹配人数，再次编辑可以调整或清除。这里是原型的目标人群配置，名单变化后人数会重新计算；不会自动生成学习记录，也不会改变已有“学习人数”。正式的课程分配与员工端权限仍需接入后端。

### 新建与编辑培训计划

“培训对象”可选全体员工、指定部门或指定员工；“课程安排”可勾选一门或多门已发布课程，草稿课程显示但不可选；“截止日期”使用页面内日历选择。新建计划至少需要一个培训对象、一门课程和截止日期。保存后计划卡展示所选对象、课程名称与完整日期，再次编辑会保留选择。旧演示计划原先只有“11 月新员工”“5 门课程”一类文字记录，编辑时会提示重新选择对象和具体课程；如果未补选，原文字记录会保留。计划配置保存在本浏览器，不会自动向员工分配课程或生成学习记录。

### 批量导入人员

在“人员管理”点击“上传人员名单”。支持 `.xlsx`、`.csv` 和 `.tsv`，可下载 Excel 模板。第一行列名至少包含“姓名”和“部门”，可选“工号”“角色”“学习进度”；学习进度支持 `72%`、`72` 或 Excel 百分比数值 `0.72`。文件限制 5 MB、2,000 行。上传后会显示可导入、重复、错误行，确认后只添加有效且未重复的人员；同工号或同姓名＋部门的记录会跳过，不覆盖现有人员。文件仅在浏览器本地读取。

### 查看与导出员工培训数据

在“培训数据”的“部门完成情况”点击部门，可筛选该部门员工；点击员工“查看明细”，可查看累计观看分钟、已通过课程数，以及每门课程的观看时长和状态。“查看全部部门”返回完整名单。当前“本月 / 本季度”控制的是上方演示指标；员工明细为累计示例记录，暂不按时间切分。

“导出全部员工数据”下载整个名单；选中部门后按钮会变成“导出本部门员工数据”，只导出当前部门。`.xlsx` 包含两个工作表：“员工培训汇总”逐人列出工号、姓名、部门、学习进度、观看分钟、通过课程数量与名称；“课程学习明细”逐人逐课程列出观看分钟和课程状态。原有五名示例员工带有明确标注的原型学习记录；通过名单导入或手动新增的员工若没有学习记录，观看分钟和通过课程列保持空白，标记为“仅人员名单”。

## 文件

- `dist/index.html`：页面入口
- `dist/styles.css`：视觉样式与响应式布局
- `dist/app.js`：员工端组件与交互
- `dist/admin.js`：角色入口、HR 管理端组件与交互
- `dist/sheets.js`：浏览器本地 Excel/CSV 导入与 Excel 导出
- `dist/vendor/`：离线 Excel 解压依赖及其许可证

这是可点击原型。角色选择不是实际身份认证；课程、人员、考试及数据均为示例，部分操作保存在本浏览器 localStorage。正式账号、权限、课程内容、考试题库、消息发送与后端数据尚未接入。不要用此原型保存正式员工名单。
